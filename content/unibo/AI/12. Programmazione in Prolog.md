# Appunti Completi: Programmazione in Prolog

## Introduzione e Sintassi
Prolog è un linguaggio basato sulla programmazione logica. Un programma Prolog è costituito da una base di conoscenza contenente fatti e regole.

### Elementi Sintattici
* **Variabili:** Iniziano sempre con una lettera maiuscola (es. `X`, `Y`, `Resto`).
* **Costanti:** Iniziano con una lettera minuscola (es. `alice`, `a`, `[]`).
* **Termini composti (Funzioni/Predicati):** Hanno la forma `functor(argomenti)` (es. `father(X)`, `brother(X,Y)`).

### Struttura del Programma
* **Fatti:** Asserzioni incondizionatamente vere. Terminano con un punto.
```prolog
piove.
padre(mario, luca).
```
La sintassi generale per le **Regole** è `Testa :- Corpo.`, che si legge "La Testa è vera SE il Corpo è vero".
```prolog
nonno(X, Y) :- padre(X, Z), padre(Z, Y).
```
## Semantica
L'esecuzione di un programma Prolog avviene tramite la **Risoluzione SLD**.
Il sistema tenta di dimostrare un **Goal** (obiettivo).
* **Regola di Selezione:** Viene sempre elaborato l'atomo più a sinistra nel goal corrente.
* **Ordine di Ricerca:** Le clausole vengono scansionate nell'ordine in cui sono scritte nel file (dall'alto verso il basso).

## Liste
Le liste sono strutture dati definite ricorsivamente.
* **Lista vuota:** `[]`.
* **Lista non vuota:** `[Testa | Coda]`.
    * `Testa` è il primo elemento.
    * `Coda` è la lista dei rimanenti elementi.
    * Esempio: `[a, b, c]` corrisponde a `[a | [b | [c | []]]]`.

### Operazioni sulle Liste

**Lunghezza (Length)**
Calcola la lunghezza `N` di una lista. Utilizza una notazione simbolica `s(N)` per il successore.
```prolog
length([], 0).
length([_|L], s(N)) :- length(L, N).
```
**Appartenenza (Member)**
Verifica se un elemento `X` è presente nella lista.
```prolog
member(X, [X|_]).
member(X, [_|L]) :- member(X, L).
```
**Concatenazione (Append)**
Relazione che unisce due liste `L1` e `L2` in una terza lista `L`.
```prolog
append([], L, L).
append([X|L1], L2, [X|L]) :- append(L1, L2, L).
```
**Cancellazione (Delete)**
Rimuove la prima occorrenza di `X` dalla lista.
```prolog
delete(X, [X|R], R).
delete(X, [Y|L], [Y|R]) :- delete(X, L, R).
```
Nota: Prolog non è tipizzato. Un predicato come `member(a, [a | non_lista])` ha successo perché l'unificazione si ferma alla testa senza controllare la coda. Per imporre un tipo lista, si può definire un predicato `list`.
```prolog
list([]).
list([_|L]) :- list(L).
```

## Aritmetica
Prolog supporta interi e numeri in virgola mobile.
Per la valutazione delle espressioni si usa l'operatore `is`, mentre `=` è l'unificazione e non valuta.
* **Uso di `is`:** `Z is X + 1`. (Richiede che `X` sia istanziato a un numero).
* **Confronti Aritmetici:**
    * `X =:= Y` (Valori uguali).
    * `X =\= Y` (Valori diversi).
    * `X > Y`, `X < Y`.

**Esempio: Merge Sort**
L'algoritmo richiede due predicati ausiliari: `split` (divide la lista) e `merge` (fonde liste ordinate).

```prolog
% Split
split([X|L], [X|L1], L2) :- split(L, L2, L1).
split([], [], []).

% Merge
merge([], Y, Y).
merge(Y, [], Y).
merge([X|L1], [Y|L2], [X|L]) :- X =< Y, merge(L1, [Y|L2], L).
merge([X|L1], [Y|L2], [Y|L]) :- X > Y, merge([X|L1], L2, L).

% Mergesort
merge_sort([], []).
merge_sort([X], [X]).
merge_sort([X,Y|R], LSort) :- 
    split([X,Y|R], L1, L2),
    merge_sort(L1, L1Sort),
    merge_sort(L2, L2Sort),
    merge(L1Sort, L2Sort, LSort).
```

## Strutture Dati e Alberi
Le strutture dati complesse sono rappresentate tramite termini composti.
Un albero binario può essere definito come:
* `void`: Albero vuoto.
* `tree(Elemento, Sinistra, Destra)`: Nodo con un elemento e due sottoalberi.

**Visita in Pre-Ordine**
Restituisce una lista con i nodi visitati (Radice, Sinistra, Destra).
```prolog
pre_visit(void, []).
pre_visit(tree(Root, Left, Right), [Root|L]) :-
    pre_visit(Left, L1),
    pre_visit(Right, L2),
    append(L1, L2, L).
```
**Rotazione (Esempio a Sinistra)**
Manipolazione strutturale dell'albero.
```prolog
rotate_left(tree(R1, Alfa, tree(R2, Beta, Delta)), tree(R2, tree(R1, Alfa, Beta), Delta)).
```

## Il Cut (!)
Il **Cut** (punto esclamativo `!`) è un operatore di controllo che permette di "potare" l'albero di ricerca SLD.
Quando eseguito:
1. Rende definitive le scelte fatte nella regola corrente fino a quel punto.
2. Impedisce il backtracking sulle alternative precedenti all'interno della regola.
3. Impedisce l'uso di altre clausole per lo stesso predicato.

**Utilizzi:**
* **Efficienza:** Evita ricerche inutili quando la soluzione è già stata trovata (es. `member` deterministico).
* **Esclusione:** Implementa logiche tipo "if-then-else".

**Esempio: Compare**
Confronta due numeri e restituisce un atomo (`minor`, `equal`, `greater`). Il cut evita controlli ridondanti.
```prolog
compare(X, Y, minor) :- X < Y, !.
compare(X, Y, equal) :- X =:= Y, !.
compare(X, Y, greater) :- X > Y.
```
**Negazione come Fallimento (Negation as Failure)**
Usando il cut insieme al predicato `fail` (che fallisce sempre), si può implementare la negazione.
```prolog
not_member(X, []).
not_member(X, [X|_]) :- !, fail.
not_member(X, [_|L]) :- not_member(X, L).
```
**Esempio: Insieme (Set)**
Rimuove i duplicati da una lista usando la negazione.
```prolog
set([], []).
set([X|L], [X|S]) :- not_member(X, L), !, set(L, S).
set([X|L], S) :- set(L, S).
```

## Liste Differenza (Difference Lists)
L'operazione `append` standard è costosa perché deve scorrere il primo argomento. Le liste differenza risolvono questo problema rappresentando una lista come la differenza tra due liste `L1 - L2`.
Esempio: la lista `[a, b]` è rappresentata come `[a, b | Z] - Z`.
Ciò consente la concatenazione in tempo costante O(1).

**Esempio: Flatten con Liste Differenza**
Appiattisce una lista di liste.
```prolog
flatten_dl([X|L], F-Z) :- flatten_dl(X, F-Y), flatten_dl(L, Y-Z).
flatten_dl(X, [X|Z]-Z) :- constant(X), X \= [].
flatten_dl([], Z-Z).
```
