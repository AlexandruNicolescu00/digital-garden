# Modulo 8: File Multimediali e Digital Forensics

## Introduzione ai File Multimediali nelle Indagini
Le indagini forensi digitali coinvolgono sempre più spesso file multimediali, spinti dalla diffusione di smartphone e dispositivi mobili. Questi file includono fotografie digitali, immagini bitmap e raster, grafica vettoriale, file audio, video e file multimediali misti. Per un esaminatore forense è cruciale comprendere le strutture interne di questi file, i metodi di compressione e le tecniche utilizzate per nascondere dati (steganografia o offuscamento).

L'obiettivo principale dell'analisi è localizzare, recuperare e autenticare questi file, gestendo sfide come file criptati, protetti da password o con intestazioni danneggiate.

---

## Tipi di File Grafici e Formati

### Fotografie Digitali
Le fotocamere digitali e gli smartphone producono principalmente due tipi di formati:

1.  **Formato Raw:**
    * È considerato il "negativo digitale".
    * I dati vengono registrati direttamente dai sensori della fotocamera senza elaborazione o compressione.
    * **Vantaggio:** Mantiene la massima qualità dell'immagine.
    * **Svantaggio:** È spesso proprietario (dipende dal produttore della fotocamera) e richiede software specifici per la visualizzazione. Il processo di conversione da Raw a formati standard è chiamato *demosaicing*.

2.  **Formato Exif (Exchangeable Image File):**
    * Sviluppato dalla JEITA, è lo standard per memorizzare metadati nei file JPEG e TIF.
    * **Metadati inclusi:** Modello della fotocamera, numero di serie, impostazioni di scatto (tempo di esposizione, apertura), data e ora, e geolocalizzazione (coordinate GPS).
    * Questi metadati sono fondamentali per collegare una foto a un dispositivo specifico o a un luogo.
    * L'analisi richiede visualizzatori specifici (es. ExifTool, Autopsy). È importante verificare la coerenza dei dati temporali (es. confrontare l'ora della foto con le ombre o gli orari di alba/tramonto del luogo).

### Immagini Bitmap e Raster
* **Bitmap/Raster:** Sono griglie di pixel. La qualità dipende dalla risoluzione (densità dei pixel) e dalla profondità di colore (bit per pixel).
    * Esempi standard: `.gif`, `.jpg`, `.png`, `.tif`, `.bmp`.
    * Se ingrandite, perdono qualità (sgranano).
* **Grafica Vettoriale:** Utilizza linee e formule matematiche invece dei pixel.
    * Esempi: `.hpgl`, `.dxf`, `.ai`.
    * Possono essere ridimensionate senza perdita di qualità e occupano generalmente meno spazio.
* **Metafile:** Combinano elementi raster e vettoriali.

### Visualizzazione dei File
Non esiste un unico visualizzatore universale. Gli investigatori devono disporre di una suite di strumenti (es. IrfanView, VLC, FastStone) per aprire formati standard e proprietari.
* **Thumbnails (Miniature):** I sistemi operativi creano file database (come `thumbs.db` in Windows) che contengono anteprime delle immagini. Questi sono preziosi perché possono mostrare prove di immagini che sono state cancellate dalla cartella principale ma la cui miniatura è rimasta nel database.

## Compressione dei Dati

La compressione è utilizzata per ridurre lo spazio di archiviazione e i tempi di trasmissione. Esistono due metodi principali:

1.  **Compressione Lossless (Senza perdita):**
    * Riduce la dimensione del file senza scartare dati.
    * Quando il file viene decompresso, è identico bit per bit all'originale.
    * Utilizzata in formati come GIF e PNG, e in archivi (ZIP).
    * Algoritmi comuni: Huffman, LZW.

2.  **Compressione Lossy (Con perdita):**
    * Scarta permanentemente alcuni dati (bit) per ridurre significativamente la dimensione.
    * La qualità dell'immagine viene ridotta (anche se spesso in modo impercettibile all'occhio umano).
    * Utilizzata in JPEG e formati video.
    * **Implicazioni forensi:** Ogni volta che un file lossy viene salvato nuovamente (non solo rinominato), la compressione viene riapplicata, degradando ulteriormente la qualità (Vector Quantization è una forma di compressione lossy).

## Steganografia e Offuscamento

### Steganografia
È l'arte di nascondere informazioni ("scrittura nascosta") all'interno di un file ospite (host file) in modo che l'esistenza stessa del messaggio segreto non sia nota a terzi.
* **Inserimento:** I dati vengono inseriti in parti del file che non vengono visualizzate (es. dopo il marker di fine file).
* **Sostituzione:** I bit meno significativi (LSB) del file ospite (spesso un'immagine o un audio) vengono sostituiti con i bit del messaggio segreto. Poiché l'occhio umano non distingue piccole variazioni di colore, l'immagine appare normale.

**Steganalysis (Rilevamento):** È difficile rilevare la steganografia se non si possiede il file originale per un confronto (Known cover attack). Gli investigatori cercano discrepanze nella dimensione del file, nella qualità o usano strumenti specifici per rilevare firme steganografiche.

### Altre Tecniche di Offuscamento
1.  **Bit-Shifting:** Spostare i bit a sinistra o a destra per alterare i valori dei byte, rendendo i dati illeggibili o facendoli apparire come codice binario eseguibile. Gli editor esadecimali possono essere usati per invertire il processo.
2.  **Cambio dell'estensione:** Rinominare un file `.xlsx` in `.jpg` impedisce l'apertura con il programma corretto. Tuttavia, l'analisi dell'intestazione (header) del file rivela la vera natura del file (mismatch tra estensione e header).
3.  **File o Partizioni Nascoste:** Utilizzare gli attributi "Nascosto" del sistema operativo o manipolare la tabella delle partizioni per creare aree non allocate o volumi non montati dove nascondere dati.

## Copyright e Watermarking
Nelle indagini aziendali, è fondamentale verificare la violazione del copyright.
* Non esiste una legge internazionale unica sul copyright, ma trattati tra paesi.
* **Digital Watermarking:** È una forma di steganografia usata per proteggere il copyright. Può essere visibile (loghi sovrapposti) o impercettibile (modifica dei bit del file per inserire una firma digitale che prova la proprietà).

## Localizzazione e Recupero di File Multimediali

### Analisi dell'Intestazione (Header)
Ogni file ha una firma esadecimale univoca all'inizio (Header) e spesso un marcatore di fine (Footer/Trailer).
* **Esempio JPEG:** Inizia con `FF D8` e finisce con `FF D9`.
* **Esempio TIF:** Inizia con `49 49 2A`.
Se un file ha un'intestazione danneggiata o alterata intenzionalmente, l'investigatore può usare un editor esadecimale (come HxD) per riparare l'intestazione inserendo i valori corretti, rendendo il file nuovamente visualizzabile.

### Carving dei Dati
Quando i file sono cancellati o frammentati e non ci sono riferimenti nel file system, si utilizza il *File Carving*. Questa tecnica scansiona lo spazio non allocato o lo slack space alla ricerca di intestazioni e piè di pagina noti per "ritagliare" e ricostruire i file.

## Crittografia e Password

### File Criptati e Password
I sospettati possono usare la crittografia o password per proteggere i file (singoli file, archivi ZIP/RAR o interi dischi).
* **Attacco a Dizionario:** Usa elenchi di parole comuni.
* **Brute-Force:** Tenta tutte le combinazioni possibili di caratteri. È lento e richiede molte risorse.
* **Rainbow Tables:** Tabelle pre-calcolate di hash per velocizzare il cracking delle password.
* **Salting:** Tecnica che aggiunge bit casuali alla password prima dell'hashing per rendere inefficaci le Rainbow Tables.

### Gestione della Crittografia
Se non è possibile recuperare la password, si possono cercare file di chiavi, provare password ricavate dal profilo dell'utente (date, nomi) o utilizzare software forensi che tentano il recupero.

## Validazione delle Prove (Hashing)

L'integrità delle prove è fondamentale.
* **Hashing:** Algoritmi come MD5 o SHA-1 generano un'impronta digitale univoca di un file o di un disco. Se anche un solo bit cambia, l'hash cambia completamente.
* **Uso pratico:**
    1.  Si calcola l'hash del drive originale.
    2.  Si crea l'immagine forense.
    3.  Si calcola l'hash dell'immagine. Se i due hash coincidono, la copia è perfetta.
* **KFF (Known File Filter) e NSRL:** Database di hash di file noti (sistema operativo, software legittimo). Permette di filtrare ed escludere i file "buoni" per concentrarsi solo sui file sconosciuti o sospetti (o per cercare file "cattivi" noti tramite il loro hash).
* **Block-wise Hashing:** Hashing di blocchi o settori specifici per identificare frammenti di file noti in spazi non allocati.

## Pianificazione dell'Esame

Un'indagine deve seguire un piano strutturato ma flessibile:
1.  **Preparazione:** Preservare le prove (specialmente su SSD dove il comando TRIM può cancellare i dati), definire gli obiettivi basati sulla richiesta del cliente/legale.
2.  **Acquisizione:** Usare write-blocker e creare immagini forensi verificate.
3.  **Analisi:**
    * Esplorare la struttura delle directory.
    * Recuperare file cancellati.
    * Identificare file protetti da password.
    * Analizzare file eseguibili sconosciuti.
    * Cercare discrepanze (es. estensioni file false).
4.  **Reporting:** Documentare ogni passo, i tool usati e i risultati ottenuti in modo chiaro.
