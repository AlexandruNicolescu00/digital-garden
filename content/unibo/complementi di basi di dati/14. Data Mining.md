## 1. Cos'è il Data Mining?

Il **Data Mining** è il processo computazionale volto alla scoperta di **pattern** (modelli ricorrenti) all'interno di grandi set di dati. Si colloca all'intersezione tra machine learning, statistica e sistemi di database.
L'obiettivo finale è estrarre **conoscenza** da grandi moli di dati grezzi.

### Concetti Chiave
* **Pattern:** Regolarità nei dati che si ripetono in modo prevedibile.
    * *Esempio:* "Il prezzo di una casa è circa 2500 volte i suoi metri quadri" oppure "Chi compra un PC spesso compra poi una fotocamera digitale".
* **Conoscenza (Knowledge):** È la comprensione nuova e utile derivata dai pattern scoperti. Permette di descrivere fenomeni e fare previsioni.
    * *Esempio:* Capire come posizionare i prodotti in un supermercato in base alle associazioni di acquisto (es. latte e cereali vicini).
* **Grandi quantità di dati (Large amount of data):** Per trovare pattern statisticamente significativi e non dovuti al caso, sono necessarie molte osservazioni (esempi omogenei).

## 2. Il Processo di Data Mining

Un progetto di Data Mining segue tipicamente questi passi sequenziali:

1.  **Definizione del problema:** Qual è l'obiettivo? Quale conoscenza vogliamo estrarre?
2.  **Identificazione dei dati:** Raccolta e comprensione dei dati necessari.
3.  **Preparazione e Pre-processing:** Selezione, pulizia e formattazione dei dati per renderli adatti agli algoritmi.
4.  **Modellazione (Modeling):** Selezione degli algoritmi di Machine Learning e tuning dei parametri.
5.  **Training e Test:** Addestramento del modello su un campione di dati e verifica su dati non visti ("unseen data").
6.  **Verifica e Deployment:** Validazione finale e messa in produzione.

*In questo corso ci concentriamo sui passi 3, 4 e 5.*

## 3. Machine Learning (Apprendimento Automatico)

Il Machine Learning (ML) è il cuore del Data Mining. È il metodo con cui si astrae dai dati per trovare pattern.
L'idea base è che una funzione (modello/ipotesi) venga "imparata" automaticamente dai dati, invece di essere programmata manualmente. Questo è essenziale quando i dati sono troppi, hanno troppe variabili (alta dimensionalità) o relazioni non lineari complesse che un umano non potrebbe codificare.

### Terminologia ML
* **Esempio (Observation):** Una singola riga di dati (es. una casa).
* **Input variables (Features):** Le variabili usate per fare predizioni (es. metri quadri).
* **Output variable (Target):** La variabile da predire (es. prezzo).
* **Ipotesi (Modello):** La funzione appresa dall'algoritmo.
* **Label:** Il valore "vero" della variabile di output nel training set (Ground Truth).
* **Predizione:** Il valore stimato dal modello.

### Tipi di Apprendimento
1.  **Supervisionato (Supervised):** Il dataset di training include la **label** (l'output desiderato è noto). Il modello impara a mappare input -> output.
    * **Regressione:** L'output è un valore numerico (es. prezzo di una casa).
    * **Classificazione:** L'output è una classe o categoria (es. "La casa è a Los Angeles? Sì/No").
2.  **Non Supervisionato (Unsupervised):** Non c'è una variabile di output o label. L'obiettivo è trovare strutture nascoste nei dati.
    * **Clustering:** Raggruppare esempi simili in gruppi.
    * **Association Rules:** Scoprire relazioni tra variabili (es. carrello della spesa).
    * **Anomaly Detection:** Trovare outlier (es. frodi bancarie).

**Concetto P.A.C. (Probably, Approximately Correct):**
Essendo basato sulla statistica, il ML non è mai accurato al 100%. L'obiettivo è un modello che sia *probabilmente* corretto (alta probabilità) e *approssimativamente* corretto (basso errore di generalizzazione su nuovi dati).

## 4. Data Pre-processing

I dati del mondo reale sono "sporchi" (dirty). Il pre-processing è fondamentale ("Garbage in, garbage out").
I problemi comuni includono dati incompleti (valori mancanti), rumorosi (errori), inconsistenti o ridondanti.

Le fasi principali del pre-processing sono:

### A. Data Cleaning (Pulizia dei Dati)
Serve a gestire:
* **Dati Mancanti (Missing Values):**
    * *Soluzioni:* Ignorare la tupla (sconsigliato se si perdono troppi dati), riempire manualmente, usare una costante globale ("Unknown"), usare la **media** dell'attributo, o usare la media della classe di appartenenza.
* **Dati Rumorosi (Noisy Data):** Errori casuali o varianza.
    * *Soluzioni (De-noising):*
        * **Binning:** Ordinare i dati e raggrupparli in "bin" (cestini). Si può poi sostituire ogni valore con la media del suo bin (smoothing locale).
        * **Regressione:** Adattare i dati a una funzione matematica per ridurre il rumore.
        * **Clustering:** Identificare e rimuovere gli outlier che cadono fuori dai gruppi.

**Nota:** In ambito Data Warehouse la pulizia deve essere aggressiva. In ambito Data Mining/ML, alcuni algoritmi possono gestire il rumore tramite tecniche di "regolarizzazione", quindi a volte è meglio iniziare con modelli semplici prima di pulire eccessivamente.

### B. Data Integration (Integrazione dei Dati)
Unire dati da fonti diverse comporta problemi di eterogeneità semantica.
* **Entity Identification Problem:** Come capire se `customer_id` in un DB corrisponde a `cust_number` in un altro?
* *Soluzione:* Usare i metadati. Confrontare nomi (edit distance), tipi di dato e intervalli di valori (range) per identificare corrispondenze probabili.

### C. Data Transformation (Trasformazione dei Dati)
Gli algoritmi di ML lavorano con vettori numerici. I dati devono essere trasformati:
* **Encoding (Codifica):** Convertire dati non numerici.
    * *Testo:* Usare **Bag-of-Words (Vectorization)**, dove ogni parola è una variabile (1 se presente, 0 se assente).
    * *Categorie:* Usare **One-Hot Encoding**. Per una variabile "Città" con 3 valori possibili, si creano 3 variabili binarie (es. is_NY, is_LA, is_Boston).
* **Scaling (Normalizzazione):** I valori numerici molto grandi possono bloccare gli algoritmi di ottimizzazione.
    * *Soluzione:* Scalare i valori in un range fisso, tipicamente [0, 1] o [-1, 1], usando formule come il Min-Max scaling.
